<summary>了解统计口径与评语规则</summary>

报告根据最近采集的累计数据生成，不限定某一自然年。各项排名以当前收录的社区成员为比较范围；个性化评语根据百分位排名自动生成：

| 条件 | 评语 |
|------|------|
| Stars 百分位 ≥90% | 你是社区中的 Star 收割机 |
| Stars 百分位 ≥70% | 你参与的项目很受欢迎 |
| 贡献百分位 ≥90% | 代码贡献量名列前茅 |
| 贡献百分位 ≥50% | 持续为社区贡献代码 |
| 研究方向 ≥5 个 | 涉猎 N 个研究方向，堪称全能选手 |
| 研究方向 ≥3 个 | 在 N 个方向都有建树 |
| 深夜提交 ≥50% | 是一位资深夜猫子开发者 🦉 |
| 关注者百分位 ≥80% | 在社区中颇具影响力 |

百分位计算方式：统计所有成员中该指标比你高的人数作为排名，`百分位 = (1 - 排名/总人数) × 100`。符合多条规则时会拼接显示，均不符合则显示"继续加油，你的开源之旅才刚刚开始！"
